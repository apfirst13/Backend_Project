# Expense Tracker CLI

แอปพลิเคชันบริหารจัดการและบันทึกรายรับ-รายจ่ายส่วนตัว ผ่านระบบ Command Line Interface (CLI) พัฒนาด้วย Node.js โดยเน้นการจัดเก็บข้อมูลในรูปแบบโครงสร้าง JSON และจัดการระบบ File System บนเครื่องคอมพิวเตอร์โดยตรง

## คุณสมบัติของระบบ (Features)
- บันทึกรายการค่าใช้จ่ายใหม่พร้อมระบุคำอธิบาย วันที่ (อัตโนมัติ) และจำนวนเงิน
- แสดงรายการค่าใช้จ่ายทั้งหมดในรูปแบบตารางที่จัดหน้าอย่างเป็นระเบียบ
- อัปเดตและแก้ไขข้อมูลรายการค่าใช้จ่ายเดิมผ่านการอ้างอิง ID
- ลบรายการที่ไม่ต้องการออกจากระบบ
- สรุปยอดรวมค่าใช้จ่ายทั้งหมดในระบบ
- สรุปยอดรวมค่าใช้จ่ายแยกเฉพาะรายเดือนของปีปัจจุบัน

## เทคโนโลยีที่เลือกใช้ (Tech Stack)
- **Runtime Environment:** Node.js
- **Command Line Parser:** Commander.js
- **Data Storage:** Native File System & JSON (ระบบฐานข้อมูลจำลองในรูปแบบไฟล์เดี่ยว)
