# Task Tracker CLI

A lightweight command-line interface application designed for tracking and managing daily tasks efficiently. 

## Features
- Add, update, and delete tasks directly from the terminal.
- Persistent data storage utilizing JSON and the native file system.
- Fast and straightforward CLI operations without external database dependencies.

## Tech Stack
- Python 

## How to Run
1. Clone this repository: `git clone [your-repo-link]`
2. Navigate to the project directory.
3. Run the application: `python main.py` (ปรับคำสั่งตามจริง)
